# Pipeline Databases – AI Academy (DLH)

This repository contains my exercises on SQL and NoSQL databases as part of the AI Academy course at DLH. The project focuses on MySQL and MongoDB fundamentals including database creation, SQL queries, joins, indexes, triggers, stored procedures, views, and MongoDB document operations using both shell scripts and Python.

## 📘 Objective

To strengthen database concepts by learning:

* MySQL database management
* SQL queries and table manipulation
* Data filtering and aggregation
* SQL joins
* Views
* Triggers
* Stored procedures
* SQL functions
* Index optimization
* MongoDB shell commands
* CRUD operations in MongoDB
* MongoDB with Python using PyMongo
* Aggregation and analytics
* Working with collections and documents
